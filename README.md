## ✨ Features

- 🎮 **AWS Cloud Journey** — Game-style level progression (CLF-C02 ✅ → SAA-C03 🔥 → DevOps 🔒) with animated XP bar
- ⚡ **Animated Skill Bars** — Scroll-triggered fills for Cloud, Networking, Linux, Python, IoT & Analytics
- 🌌 **Particle Star Canvas** — Dynamic animated background
- ⌨️ **Typewriter Effect** — Role titles cycle with typewriter animation
- 📜 **Vertical Experience Timeline** — Clean card-based timeline
- 🃏 **Project Cards** — Hover-reveal cards for key projects
- 📱 **Fully Responsive** — Mobile-first with hamburger navigation
- 🔗 **Social Links** — LinkedIn, GitHub, Email, Phone

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 (custom properties, animations, grid, flexbox) |
| Logic | Vanilla JavaScript (IntersectionObserver, Canvas API) |
| Fonts | Space Grotesk + DM Sans (Google Fonts) |

> No frameworks. No dependencies. Pure HTML/CSS/JS.

## 🚀 Getting Started

Clone the repo and open directly in a browser — no build step needed.

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
# Open index.html in your browser
```

Or deploy instantly to **GitHub Pages**:

1. Go to your repo → **Settings → Pages**
2. Set source to `main` branch, root `/`
3. Your portfolio is live at `https://<your-username>.github.io/<repo-name>/`
